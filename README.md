# PhotoTrace

每一场拍摄，都有迹可循。

PhotoTrace 是一个面向独立摄影师与摄影团队的**单文件摄影工作台**。无需安装 Node.js、没有后端、不依赖云端服务器，打开网页就能用，数据全部保存在你的浏览器本地。

在线直接体验：[https://elosiad.github.io/phototrace/](https://elosiad.github.io/phototrace/)

---

## 为什么使用 PhotoTrace？

摄影从按动快门到交付成果，流程往往繁琐而零散：原片导入、iPad 移动初筛、像素蛋糕等软件批量修图、特定人物精修、交付外链整理。传统通用待办或看板工具难以直观呈现“一场拍摄包含多个人物任务与多阶段流转”的真实场景。

PhotoTrace 为此而生：
- **纯单文件**：整个应用全部内联在单个 HTML 中，直接双击运行，断网完全可用。
- **本地优先**：数据安全存储在本地浏览器（LocalStorage），支持一键导出与恢复完整 JSON 备份，客户隐私不外泄。
- **摄影专属管线**：内置 导入（30%）→ 初筛（30%）→ 修图（30%）→ 发布（10%）阶段推导，支持一人多场、批量推进与操作撤销。

## 快速使用

### 方式 1：在线直接使用
访问 [https://elosiad.github.io/phototrace/](https://elosiad.github.io/phototrace/) 即可开始记录。数据自动保留在当前浏览器的本地存储中。

### 方式 2：本地离线运行
克隆或下载本仓库，在文件管理器中**直接双击打开 `index.html`** 即可，不需要安装任何环境或运行本地服务。

## 核心特性

- **可视化拍摄看板**：清晰查看待筛选、已初筛、修图中、已完成的项目与真实进度条。
- **人物与任务流转**：同场拍摄支持多人及团体协同；在“人物任务”视图中可按阶段合并卡片，支持一键批量推进整组任务。
- **无感键盘录入**：详情页内嵌常驻录入栏，输入姓名敲回车即可直接加入拍摄。
- **硬件与存储留档**：记录 iPad / 像素蛋糕等资源占用，管理原片路径、交付位置、网盘备份与交付外链。
- **防误触与安全机制**：任务状态操作提供 10 秒即时撤销支持；具备未保存草稿保护、异常数据拦截与恢复前自动快照。
